# Project Memory

## Core
Israeli invoice app (FacturePro). Dark theme, DM Sans font. Primary accent hsl(47,100%,62%).
SmartBee (Green Invoice) is the ONLY invoice platform. No multi-provider.
Each user stores their OWN SmartBee API key in their profile. No shared key.
Lovable Cloud enabled. Edge function: export-invoice.
